# Live Look In — Event Bus Reference

## Overview

The Event Bus is the nervous system connecting real agent processes to Live Look In. Agents emit lightweight JSON events; the State Engine consumes them and updates the world model; the Renderer displays the result.

```
┌─────────────┐    ┌───────────┐    ┌──────────────┐    ┌──────────┐
│ Agent Process│───>│  Redis    │───>│ State Engine  │───>│ Renderer │
│ (SDK emit)  │    │  Pub/Sub  │    │ (aggregator)  │    │ (WS)     │
└─────────────┘    └───────────┘    └──────────────┘    └──────────┘
```

## Event Protocol

All events follow this envelope:

```json
{
  "v": 1,
  "org_id": "achievemor",
  "agent_id": "ba-0",
  "agent_name": "API_Ang",
  "agent_type": "boomerang",
  "event": "task.started",
  "timestamp": 1711000000000,
  "payload": { ... }
}
```

### Event Types

| Event            | When                      | Payload                                         |
|------------------|---------------------------|--------------------------------------------------|
| `agent.online`   | Agent process starts      | `{ dept, specialty }`                            |
| `agent.offline`  | Agent process stops       | `{ reason }`                                     |
| `task.assigned`  | Agent receives a task     | `{ task_id, title, complexity, dept }`           |
| `task.started`   | Agent begins execution    | `{ pcp }` (full PCP object)                     |
| `task.progress`  | Periodic progress update  | `{ progress: 0-100, step_description }`          |
| `task.completed` | Agent finishes task       | `{ score, grade, duration_ms, result_summary }`  |
| `task.failed`    | Agent encounters error    | `{ error, retry_count, will_retry }`             |
| `agent.moving`   | Agent transitioning rooms | `{ from_room, to_room }`                        |
| `agent.break`    | Agent entering break room | `{ last_task_id }`                               |

### Channels

- `livelookin:{org_id}:events` — All agent events
- `livelookin:{org_id}:commands` — Control messages (pause agent, reassign task)
- `livelookin:{org_id}:state` — Periodic full state snapshots

## Transport Phases

### Phase 2 — REST Polling

```
GET /api/live-look-in/state
Accept: application/json
If-None-Match: "{etag}"

Response 200:
{
  "agents": AgentState[],
  "events": WorkforceEvent[],
  "pcps": PCPDocument[],
  "timestamp": number,
  "etag": string
}

Response 304: Not Modified
```

- **Poll interval**: 5000ms (configurable)
- **Stale threshold**: 30s — show "disconnected" badge

## Agent SDK (Python)

Agents integrate with Live Look In by importing the SDK and emitting events at natural checkpoints. The SDK is non-blocking and has zero impact on agent performance.

```python
# pip install livelookin-sdk

from livelookin import LiveLookInAgent

# Initialize once
agent = LiveLookInAgent(
    agent_id="ba-0",
    agent_name="API_Ang",
    agent_type="boomerang",
    dept="engineering",
    redis_url="redis://localhost:6379",
    org_id="achievemor"
)

# In your agent's task loop:
async def execute_task(task):
    # Signal task assignment
    agent.emit_task_assigned(
        task_id=task.id,
        title=task.title,
        complexity=task.complexity
    )

    # Generate and emit PCP
    pcp = agent.generate_pcp(task)
    agent.emit_task_started(pcp=pcp)

    # During execution, emit progress
    for step_idx, step in enumerate(task.steps):
        result = await step.execute()
        agent.emit_progress(
            progress=(step_idx + 1) / len(task.steps) * 100,
            step_description=step.name
        )

    # On completion
    score = evaluate_result(result)
    agent.emit_task_completed(
        score=score,
        grade=agent.grade_from_score(score),
        duration_ms=elapsed,
        result_summary="Successfully deployed API gateway v2.1"
    )

    # Agent returns to break
    agent.emit_break()
```

### SDK Implementation Skeleton

```python
import json
import time
import redis.asyncio as redis

class LiveLookInAgent:
    def __init__(self, agent_id, agent_name, agent_type, dept, redis_url, org_id):
        self.agent_id = agent_id
        self.agent_name = agent_name
        self.agent_type = agent_type
        self.dept = dept
        self.org_id = org_id
        self.redis = redis.from_url(redis_url)
        self.channel = f"livelookin:{org_id}:events"

    async def _emit(self, event_type, payload):
        msg = {
            "v": 1,
            "org_id": self.org_id,
            "agent_id": self.agent_id,
            "agent_name": self.agent_name,
            "agent_type": self.agent_type,
            "event": event_type,
            "timestamp": int(time.time() * 1000),
            "payload": payload
        }
        await self.redis.publish(self.channel, json.dumps(msg))

    async def emit_task_assigned(self, task_id, title, complexity):
        await self._emit("task.assigned", {
            "task_id": task_id, "title": title,
            "complexity": complexity, "dept": self.dept
        })

    async def emit_progress(self, progress, step_description=""):
        await self._emit("task.progress", {
            "progress": round(progress, 1),
            "step_description": step_description
        })

    async def emit_task_completed(self, score, grade, duration_ms, result_summary=""):
        await self._emit("task.completed", {
            "score": score, "grade": grade,
            "duration_ms": duration_ms, "result_summary": result_summary
        })

    async def emit_break(self):
        await self._emit("agent.break", {})

    @staticmethod
    def grade_from_score(score):
        if score >= 95: return "S"
        if score >= 85: return "A"
        if score >= 70: return "B"
        if score >= 55: return "C"
        return "D"
```

## Agent SDK (Node.js / TypeScript)

```typescript
import Redis from 'ioredis';

interface LiveLookInConfig {
  agentId: string;
  agentName: string;
  agentType: 'boomerang' | 'lilhawk';
  dept: string;
  redisUrl: string;
  orgId: string;
}

class LiveLookInAgent {
  private redis: Redis;
  private channel: string;
  private config: LiveLookInConfig;

  constructor(config: LiveLookInConfig) {
    this.config = config;
    this.redis = new Redis(config.redisUrl);
    this.channel = `livelookin:${config.orgId}:events`;
  }

  private async emit(event: string, payload: Record<string, any>) {
    const msg = {
      v: 1,
      org_id: this.config.orgId,
      agent_id: this.config.agentId,
      agent_name: this.config.agentName,
      agent_type: this.config.agentType,
      event,
      timestamp: Date.now(),
      payload,
    };
    await this.redis.publish(this.channel, JSON.stringify(msg));
  }

  async taskAssigned(taskId: string, title: string, complexity: string) {
    await this.emit('task.assigned', { task_id: taskId, title, complexity, dept: this.config.dept });
  }

  async progress(progress: number, step?: string) {
    await this.emit('task.progress', {
      progress: Math.round(progress * 10) / 10,
      step_description: step || ''
    });
  }

  async taskCompleted(score: number, grade: string, durationMs: number, summary?: string) {
    await this.emit('task.completed', {
      score, grade, duration_ms: durationMs, result_summary: summary || ''
    });
  }

  async onBreak() {
    await this.emit('agent.break', {});
  }
}
```

## State Engine (WebSocket Server)

The State Engine subscribes to Redis, maintains world state, and pushes diffs to connected viewers.

```python
# FastAPI + WebSocket + Redis subscriber

from fastapi import FastAPI, WebSocket
import redis.asyncio as redis
import json, asyncio

app = FastAPI()
world_state = {}  # agent_id -> agent state
connections = set()

@app.on_event("startup")
async def subscribe_to_events():
    r = redis.from_url("redis://localhost:6379")
    pubsub = r.pubsub()
    await pubsub.subscribe("livelookin:achievemor:events")

    async def listener():
        async for message in pubsub.listen():
            if message["type"] == "message":
                event = json.loads(message["data"])
                update_world_state(event)
                await broadcast_diff(event)

    asyncio.create_task(listener())

def update_world_state(event):
    aid = event["agent_id"]
    if aid not in world_state:
        world_state[aid] = {
            "id": aid, "name": event["agent_name"],
            "type": event["agent_type"]
        }

    agent = world_state[aid]
    etype = event["event"]
    payload = event["payload"]

    if etype == "task.assigned":
        agent["state"] = "traveling_to_work"
        agent["task"] = payload
        agent["room"] = payload.get("dept", agent.get("room"))
    elif etype == "task.started":
        agent["state"] = "working"
        agent["pcp"] = payload.get("pcp")
    elif etype == "task.progress":
        agent["progress"] = payload["progress"]
    elif etype == "task.completed":
        agent["state"] = "returning"
        agent["last_score"] = payload["score"]
        agent["last_grade"] = payload["grade"]
    elif etype == "agent.break":
        agent["state"] = "break"
        agent["room"] = "breakroom"

@app.websocket("/ws")
async def websocket_endpoint(ws: WebSocket):
    await ws.accept()
    connections.add(ws)
    # Send full state on connect
    await ws.send_json({"type": "full_state", "data": world_state})
    try:
        while True:
            await ws.receive_text()  # keepalive
    except:
        connections.discard(ws)

async def broadcast_diff(event):
    msg = json.dumps({"type": "event", "data": event})
    dead = set()
    for ws in connections:
        try:
            await ws.send_text(msg)
        except:
            dead.add(ws)
    connections -= dead
```

## Integration Checklist

When connecting a real agent to Live Look In:

1. Install the SDK (`pip install livelookin-sdk` or npm equivalent)
2. Initialize with agent credentials and Redis connection
3. Add `emit_task_assigned()` where your agent picks up work
4. Add `emit_progress()` in your execution loop
5. Add `emit_task_completed()` at job finish
6. Add `emit_break()` when agent goes idle
7. Verify events appear in the viewer
8. No changes needed to the agent's core logic — the SDK is observational only
