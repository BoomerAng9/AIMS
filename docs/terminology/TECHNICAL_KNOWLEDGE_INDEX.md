# Technical Knowledge Index

This file is the canonical terminology index for A.I.M.S. product and build language.

## Required Record Shape

Each term should eventually include:

- canonical term
- domain
- definition
- plain-language aliases
- related terms
- examples
- non-examples
- prompting hints
- confidence or approval status

## Canonical Terms

### Data Source Catalog

User-facing library of reusable sources.

### Context Pack

Reusable bundle of sources, artifacts, and guidance.

### Working Notebook

Session-specific composition of selected Context Packs.

### Session Snapshot

Persisted record of active context, tools, artifacts, and state.

### Index Entry: Technical Knowledge Index

Canonical technical terminology knowledge base.

### Lay-to-Technical Lexicon

Mapping layer from plain language to canonical technical terms.

### Build Intent Resolver

Engine that infers what the user is trying to build.

### Prompt Reconstruction Layer

Layer that rewrites user language into build-ready prompts.

### Data Source Registry

System of record for sources, artifacts, permissions, versions, and adapters.

### Sandbox Control Plane

System that provisions, renews, monitors, and destroys execution environments.

### Session Memory Store

Durable store for chat history, retrieval context, summaries, and checkpoints.

### Bottom Composer Bezel

Docked chat composer shell at the bottom of the thread.

### Composer Toolbar

Inline controls rendered inside the Bottom Composer Bezel.

### Voice Capture Toggle

Microphone control used to start or stop live capture.

### Attachment Trigger

Control used to attach files or source material.

### Model Selector

Inline model switcher inside the Bottom Composer Bezel.

### Data Source Picker

Inline selector for Context Packs or data sources inside the Bottom Composer Bezel.

### Speech Output Toggle

Read-aloud on or off control for assistant speech output.

### Prompt Composer

Multiline text input where the user drafts the message.

### Send Action

Control that submits the current prompt.
